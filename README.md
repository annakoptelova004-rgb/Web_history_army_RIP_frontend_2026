# Армейский марш — Frontend

## Описание проекта

«Армейский марш» — веб-приложение для отображения и просмотра информации о родах войск. Frontend-часть разработана с использованием React и TypeScript.

Приложение взаимодействует с серверной частью на Go через REST API и получает данные о родах войск, которые отображаются в пользовательском интерфейсе.

## Используемые технологии

- React
- TypeScript
- Vite
- React Router
- React Bootstrap
- CSS
- Docker

## Основные возможности

- Отображение записей в разделе «Лента».
- Просмотр списка родов войск в разделе «Плитка».
- Фильтрация записей по скорости.
- Отображение изображений записей.
- Использование изображения по умолчанию, если собственное изображение отсутствует.
- Получение данных с backend через API.

## Структура проекта

- `src/components` — переиспользуемые компоненты интерфейса.
- `src/pages` — страницы приложения.
- `src/data` — получение и преобразование данных API.
- `src/types` — типы TypeScript.
- `public` — статические изображения и другие ресурсы.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить frontend в режиме разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу:

`http://localhost:3000`

Для получения данных необходимо также запустить backend-сервер.
